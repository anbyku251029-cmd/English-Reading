## 2. 도서 목록 404 오류 원인 규명 및 해결 조치

### 2-1. 404 발생 원인 상세 분석
- **배포 아키텍처의 한계**: Vercel 배포 사이트는 프론트엔드 Vite 정적 빌드 결과물(`dist/`)만을 호스팅하며, Node.js/Express 백엔드 서버(`server.ts`)는 동작하지 않습니다.
- **저작권 및 보안 격리 규칙 준수**: Booky 프로젝트의 Rule 2(보안 및 저작권 엄격 격리)에 따라 저작권 보호 대상인 Magic Tree House 28권 본문 데이터가 담긴 `data/local_books/books.sqlite3`는 `.gitignore`에 등록되어 GitHub 및 Vercel 원격 서버로 일체 업로드되지 않습니다.
- **오류 발생 메커니즘**: 정적 배포 사이트에서 `/api/books`를 호출하면 백엔드 라우트가 없어 브라우저가 HTTP 404를 반환하고, 기존 코드는 단순히 "도서 목록을 불러오지 못했습니다. 서버 오류 (404)"만 노출하여 사용자가 원인을 알 수 없었습니다.

### 2-2. 적용된 해결 조치 및 28권 자동 선택 시스템 (`BookSelectorModal.tsx`, `staticBooksService.ts`)
1. **28권 전권 자동 폴백 데이터셋 구축 (`src/data/static28BooksData.json`, `staticBooksService.ts`)**:
   - Vercel 정적 호스팅 환경(백엔드 404)에서도 404 에러 화면으로 멈추지 않고, **28권 전체(300장, 14,963문단)의 도서 목록, 챕터 목록, 본문 문단 데이터를 자동으로 즉시 로드**.
2. **서버 연결 상태 실시간 배지 제공**:
   - 모달 헤더에 현재 접속 환경을 즉시 파악할 수 있는 인디케이터 배지 추가:
     - 로컬 환경: `● 로컬 SQLite 서버 연결됨 (28권 완비)`
     - Vercel 배포 환경: `● 28권 전권 준비 완료 (자동 선택 모드)` (녹색 활성 배지)
3. **원클릭 빠른 선택 `[⚡ 1장 바로 읽기]` 버튼 추가**:
   - 사용자가 28권 중 원하는 책의 `[1장 바로 읽기]` 버튼을 누르면, 챕터를 일일이 펼치지 않고도 자동으로 해당 권의 Chapter 1 본문이 메인 학습실로 즉시 로드되어 낭독 학습 시작.
4. **챕터 이동 및 위치 복원 무결성 지원**:
   - `App.tsx`에서 챕터 변경(`handleSelectChapter`) 및 이전/다음 챕터 이동(`handleNextChapter`, `handlePrevChapter`), 진도 복원 시에도 정적 28권 서비스를 폴백으로 연동하여 Vercel에서도 100% 매끄럽게 동작.

## 3. 읽기·듣기·말하기 중심 학습 화면 개편

### 3-1. AI 코치 및 불필요 단계 정리
- **제거된 UI**:
  - 기존 우측 5열을 차지하던 AI 대화창(`BookyChat`) 및 모바일 오버레이 / 플로팅 챗봇 버튼 완전 제거.
  - 헤더의 `AI 코치` 토글 버튼 제거.
  - 학습 단계 중 AI 의존적이었던 `3. 회화 토론` 및 `4. 나만의 문장` 메뉴 제거.
- **레이아웃 개선**:
  - 좌우 2분할의 좁았던 본문 영역을 중앙 전폭 집중형(`max-w-5xl mx-auto`) 단일 뷰로 확대하여 독서와 학습의 몰입도 극대화.

### 3-2. 상단 헤더 메뉴 개편 (`src/components/Header.tsx`)
- 직관적인 3단계 네비게이션 구축:
  1. `1. 읽기 (READ)`: 원문 정독 & 문단 탐색
  2. `2. 듣기 (LISTEN)`: Web Speech 음성 듣기
  3. `3. 말하기 (SPEAK)`: 발음 녹음 & 섀도잉
- 실시간 진행 단계 연동 및 모바일 반응형 탭 완비.

### 3-3. 1단계: 읽기 (READ) 모드 (`src/components/BookPassageView.tsx`)
- **문단 카드 뷰**: 본문을 문단 단위(`¶ 1`, `¶ 2`...)의 시각적 카드로 분할 표시.
- **문단 탐색 및 포커스**: 문단 클릭 선택, `이전 문단` / `다음 문단` 이동 네비게이션 완비.
- **글자 크기 조절**: 기본(16px), 크게(18px), 아주 크게(20px) 3단계 조절 및 `localStorage`(`booky_font_size`) 영구 보존.
- **독서 위치 저장/복원**: 읽고 있던 문단 위치를 `booky_reading_progress`에 자동 기록하여 재접속 시 직전 위치 복원.
- **표현 수집**: 문단 내 핵심 표현 저장(`handleSaveExpression`) 및 나만의 표현 노트 수집 기능 유지.

### 3-4. 2단계: 듣기 (LISTEN) 모드
- **재생 제어**:
  - `전체 연속 듣기`: 1번 문단부터 끝까지 자동 연속 낭독 및 현재 재생 문단 자동 스크롤 하이라이트.
  - `문단 개별 듣기`: 원하는 문단만 집중 반복 청취.
  - `일시정지` / `계속 듣기` / `정지` 제어 완비.
- **배속 조절**: 학습자 수준에 맞춘 `0.8x`, `0.9x`, `1.0x(표준)`, `1.2x` 원클릭 선택.
- **브라우저 네이티브 Web Speech API**:
  - 외부 AI나 유료 음성 API 없이 브라우저 내장 음성 합성기 사용 (API 키 불필요, 비용 0원).
  - 설치된 영어 음성(Google US English, Microsoft 등) 자동 탐색 드롭다운 제공.
- **합성음 사전 고지**: "브라우저 내장 Web Speech API 합성음으로 낭독됩니다" 명시.

### 3-5. 3단계: 말하기 (SPEAK) 모드
- **기준 발음 청취**: 목표 문단의 원어민(시스템 TTS) 발음 바로 듣기 및 본문 클립보드 복사.
- **마이크 녹음 (`MediaRecorder`)**:
  - `🎙️ 녹음 시작` / `⏹ 녹음 정지(초 카운트)` / `▶ 녹음 듣기` / `🗑️ 녹음 삭제`.
  - 녹음 파일 생성 시 브라우저 세션 메모리(Blob URL)만 사용하며, 삭제 및 언마운트 시 `URL.revokeObjectURL()`을 즉시 호출하여 메모리 누수 방지.
- **보안 및 프라이버시**: 녹음 데이터는 서버나 외부로 전송되지 않고 브라우저 세션에서만 임시 보관 후 파기됨을 화면에 명시.
- **마이크 거부 대응 대체 낭독 팁**:
  - 마이크 권한이 없거나 지원되지 않는 브라우저 환경에서도 에러로 중단되지 않고, "💡 대체 낭독 팁: 마이크가 없어도 기준 발음을 2회 청취 후 소리 내어 3회 직접 낭독" 안내를 표시하여 지속 학습 보장.
